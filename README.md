# OpenHub

Minijuegos open source para jugar en el navegador, sin registro y sin instalar nada.

OpenHub es un proyecto **de la comunidad**: los juegos, las mejoras y el rumbo del proyecto los decidimos entre todos.

> Este documento está vivo y se irá completando a medida que avance el proyecto.

## Cómo contribuir

Toda ayuda es bienvenida: juegos nuevos, errores, traducciones, documentación o ideas.

1. Abre un [issue](../../issues) para comentar lo que quieres hacer.
2. Haz un fork del repositorio y crea una rama: `git checkout -b mi-mejora`
3. Haz tus cambios y guárdalos: `git commit -m "Add snake game"`
4. Sube la rama: `git push origin mi-mejora`
5. Abre un pull request explicando qué has cambiado y por qué.

## Reglas

- Escribe los mensajes de commit en inglés, claros y breves.
- Usa solo imágenes y sonidos propios o con licencia compatible, indicando la autoría.
- El contenido debe ser apto para todos los públicos y sin publicidad ni rastreadores.
- Prueba tus cambios antes de abrir un pull request.
- Añade esta línea al principio de cada archivo de código:

```
// SPDX-License-Identifier: AGPL-3.0-or-later
```
