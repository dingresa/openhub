# OpenHub

Open-source minigames to play in your browser, with no registration and no installation required.

OpenHub is a **community-driven** project: the games, improvements, and direction of the project are decided by everyone.

> This document is alive and will be updated as the project progresses.

## How to contribute

All help is welcome: new games, bug fixes, translations, documentation, or ideas.

1. Open an [issue](../../issues) to discuss what you want to do.
2. Fork the repository and create a branch: `git checkout -b my-improvement`
3. Commit your changes: `git commit -m "Add snake game"`
4. Push the branch: `git push origin my-improvement`
5. Open a pull request explaining what you changed and why.

## Rules

- Write clear and concise commit messages in English.
- Use only your own images and sounds or those with a compatible license, crediting authorship.
- Content must be suitable for all audiences, with no ads or trackers.
- Test your changes before opening a pull request.
- Add this line at the top of every code file:

```
// SPDX-License-Identifier: AGPL-3.0-or-later
```
